# boringquantsystems.github.io

The BoringQuantSystems website: exact, reproducible engines for markets. A machine-made house.

The page is built by the machine-made site generator
([machine-made/machine-made.github.io](https://github.com/machine-made/machine-made.github.io)),
the same code, look and tab row as every house. This repository holds the built site in `docs/`.

## Change the site

The content lives in the generator repository, `houses/boringquantsystems/site.json`, with its
public list in `houses/boringquantsystems/allow.json`. Build it into this repository and open a
pull request:

```
sh publish.sh boringquantsystems ../boringquantsystems.github.io
```

Do not edit `docs/` by hand.
